Set up Frame Bender

Frame Bender shows a mod by replacing a character's .pak file in the game folder. Before it changes anything, it keeps a copy of the original, so one click puts the game back as it was.

1Game folder

Looking for the game…

To find it yourself: in Steam, right-click the game, choose Manage, then Browse local files, and open the data_packages folder.

2Back up characters

A backup is a copy of the character's file as it is right now. If other mods have been used on this game, verify the game files in Steam first (right-click the game, Properties, Installed Files, Verify). Each backup takes about twice the file's size on disk. More characters can be added later from the menu.

Finding and backing up characters only reads the game folder. Only Build & install and Restore original ever write to it. Modified files have been tested in online matches without issues. As with any mod, the game's developers could change their rules at any time, so use Frame Bender at your own risk.

Palette colours

Palette

Pick a costume slot to recolour it. Edit a spare slot rather than the default one, so the default look stays intact, then choose that colour at character select.

How colours work

  1. Every part of a character uses a palette row: skin is one row, the robe another. Each row holds three colours: shadow, base and light.
  2. The palette image in this folder shows every colour the game can use. Pick the colours for your painting from it. A colour that is not in the image is swapped for the closest one that is.
  3. Paint a part with a palette colour, then change that row later. Once the PNG is back in Frame Bender, you can turn that row into any colour in the Palette panel. Everything painted with it changes together, and no colour is off limits there.
  4. Want two colours in one place? Paint it with colours from two different rows.
  5. Parts you don't touch stay exactly as the game made them. Effects (fire, wind) are full colour and have no palette limit.

Export folder

A folder named after the move is made inside it. Dropping PNGs back works from any folder.

Share skin

The pack contains only your PNGs and colour changes, never the game's own files. Whoever imports it needs the game; their editor fits your art to their copy.
