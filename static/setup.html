Frame Bender

Add the tool scripts

Frame Bender reads and writes the game's files with four scripts from avatar-legends-tools by calebrisc. They are not included with Frame Bender, so they need to be added once.

Download them

Gets the four scripts (under 100 KB together) from the avatar-legends-tools repository on GitHub, at the version Frame Bender was tested with. Each file is checked against a known checksum before it is saved. Nothing else is downloaded.

    Or add them yourself

    1. Open github.com/calebrisc/avatar-legends-tools and choose Code, then Download ZIP.
    2. Copy munged_extract.py, pak_extract.py, munged_encode.py and type3_encode.py into the folder that Open the folder shows.
    3. Click Check again.
